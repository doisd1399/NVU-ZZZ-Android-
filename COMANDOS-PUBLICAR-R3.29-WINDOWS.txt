R3.29 e uma correcao Android/nativa do detector GTO. Web 2.3.9 e Firebase Functions nao mudaram.

1) PREPARAR-ANDROID-WINDOWS.bat
2) GERAR-APK-DEBUG-WINDOWS.bat
3) Instalar:
   "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" devices
   "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" install -r android\app\build\outputs\apk\debug\app-debug.apk

Se houver INSTALL_FAILED_UPDATE_INCOMPATIBLE:
   "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" uninstall com.nvu.operacional
   "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" install android\app\build\outputs\apk\debug\app-debug.apk

Nao e necessario republicar Firebase Functions ou Netlify para a R3.29, pois esta release altera apenas o codigo nativo Android e seus testes.
