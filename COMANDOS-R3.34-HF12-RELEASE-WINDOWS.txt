PREPARAÇÃO RECOMENDADA
1. Extraia o ZIP em uma pasta curta, por exemplo:
   C:\NVU\R3.34-PC-HF12

2. Abra CMD nessa pasta e execute:
   PREPARAR-ANDROID-WINDOWS.bat

O preparador executa:
- npm ci
- lint
- build das Functions somente para validação local
- npm run verify:release
- npm run build
- prepare:cap-assets
- npx cap sync android
- verify:cap-assets
- Gradle :app:compileDebugJavaWithJavac com Java 21

BUILD RELEASE LOCAL (sem assinatura configurada no projeto)
   cd android
   gradlew.bat clean assembleRelease --no-daemon

IDENTIDADE ESPERADA
   applicationId: com.nvu.operacional
   EXPECTED_VERSION_CODE: "64"
   EXPECTED_VERSION_NAME: "1.0.64"

ARTEFATO ASSINADO PELO WORKFLOW GITHUB
   NVU-R3.34-PC-HF12-release.apk

INSTALAÇÃO ADB
   "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" devices
   "%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" install -r "C:\CAMINHO\NVU-R3.34-PC-HF12-release.apk"
