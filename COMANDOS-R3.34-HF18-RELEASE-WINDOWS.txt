PREPARAÇÃO RECOMENDADA
1. Extraia o ZIP em uma pasta curta, por exemplo:
   C:\NVU\R3.34-PC-HF18

2. Abra CMD nessa pasta e execute:
   PREPARAR-ANDROID-WINDOWS.bat

O preparador executa:
- npm ci
- lint
- build das Functions somente para validação local
- npm run verify:release
- npm run build
- prepare:cap-assets
- npx cap sync android
- verify:cap-assets
- Gradle :app:compileDebugJavaWithJavac com Java 21

BUILD RELEASE LOCAL (sem assinatura configurada no projeto)
   cd android
   gradlew.bat clean assembleRelease --no-daemon
