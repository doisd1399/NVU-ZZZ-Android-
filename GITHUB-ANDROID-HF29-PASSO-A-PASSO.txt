HF29 — Android 1.0.81 / versionCode 81
GitHub pelo Android + Codespaces

1. Envie somente NVU-CAPACITOR-ANDROID-R3.34-PC-HF29.zip temporariamente para o main pelo GitHub web.
2. No Codespace:
   git pull
   ls -lh *HF29*.zip
3. Extraia em /tmp:
   ZIP="NVU-CAPACITOR-ANDROID-R3.34-PC-HF29.zip"
   rm -rf /tmp/hf29 && mkdir -p /tmp/hf29
   unzip -q "$ZIP" -d /tmp/hf29
   SRC="/tmp/hf29/NVU-CAPACITOR-ANDROID-R3.34-PC-HF29"
4. Confira antes de substituir:
   grep -nE "versionCode|versionName" "$SRC/android/app/build.gradle"
   Esperado: versionCode 81 / versionName "1.0.81"
5. Backup local e substituição segura:
   git branch -f backup-pre-hf29 HEAD
   rsync -a --delete --exclude='.git' "$SRC/" ./
   rm -f NVU-CAPACITOR-ANDROID-R3.34-PC-HF29.zip
6. Valide:
   npm ci
   npm run verify:release
7. Se tudo passar:
   git add -A
   git commit -m "NVU R3.34 PC-HF29 Android 1.0.81"
   git push origin main
8. GitHub > Actions > Build NVU R3.34 PC-HF29 Release > Run workflow > main > Run workflow.
9. Se verde, baixe o artifact NVU-R3.34-PC-HF29-release.
