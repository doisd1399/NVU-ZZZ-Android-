HF30 — Android 1.0.82 / versionCode 82
GitHub pelo Android + Codespaces

1. Envie somente NVU-CAPACITOR-ANDROID-R3.34-PC-HF30.zip temporariamente para o main pelo GitHub web.

2. No Codespace:
   git pull
   ls -lh *HF30*.zip

3. Extraia em /tmp:
   ZIP="NVU-CAPACITOR-ANDROID-R3.34-PC-HF30.zip"
   rm -rf /tmp/hf30 && mkdir -p /tmp/hf30
   unzip -q "$ZIP" -d /tmp/hf30
   SRC="/tmp/hf30/NVU-CAPACITOR-ANDROID-R3.34-PC-HF30"

4. Confira a identidade antes de substituir:
   grep -nE "versionCode|versionName" "$SRC/android/app/build.gradle"
   Esperado: versionCode 82 / versionName "1.0.82"

5. Faça backup local e substitua de forma segura:
   git branch -f backup-pre-hf30 HEAD
   rsync -a --delete --exclude='.git' "$SRC/" ./
   rm -f NVU-CAPACITOR-ANDROID-R3.34-PC-HF30.zip

6. Valide:
   npm ci
   npm run verify:release

7. Se tudo passar:
   git add -A
   git commit -m "NVU R3.34 PC-HF30 Android 1.0.82"
   git push origin main

8. GitHub > Actions > Build NVU R3.34 PC-HF30 Release > Run workflow > main > Run workflow.

9. Se verde, baixe o artifact:
   NVU-R3.34-PC-HF30-release

O workflow HF30 preserva:
- checkout limpo sem depender de assets Capacitor pré-gerados;
- parser compatível com apksigner V3;
- versionCode 82 / versionName 1.0.82;
- validação opcional EXPECTED_SIGNING_CERT_SHA256;
- concurrency group isolado da HF29;
- build de Release assinado com os secrets/keystore configurados no repositório.
