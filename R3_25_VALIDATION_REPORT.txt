LIMITAÇÃO DO AMBIENTE DE CERTIFICAÇÃO
O ambiente de geração deste ZIP não possui acesso de rede para baixar a distribuição
Gradle/Android SDK e por isso não produz o APK binário aqui. O código Java Android é
compilado pelos testes de sintaxe/fixtures, e o projeto inclui os BATs para o build real
com Android Studio/JDK 21 no Windows. O usuário já confirmou que esse ambiente Windows
consegue executar o Gradle da base R3.24; a R3.25 mantém a mesma toolchain e sobe apenas
para versionName 1.0.42 / versionCode 42.
