LIMITAÇÃO DO AMBIENTE DE ENTREGA
O ambiente usado nesta auditoria não possui o Android SDK completo para gerar o
binário Gradle final. Por isso o APK deve ser compilado no Windows com o Android
Studio/SDK do motorista. O pacote inclui duas barreiras para evitar um APK errado:

1) PREPARAR-ANDROID-WINDOWS.bat instala dependências limpas, executa lint, build das
   Firebase Functions, toda a certificação, build Web e cap sync.
2) GERAR-APK-DEBUG-WINDOWS.bat recusa a compilação se os assets Android não forem
   exatamente os do build Web 2.3.7/R3.26 sincronizado.

A validação acima certifica as regras e caminhos de código cobertos pela suíte; a
confirmação final em hardware continua dependendo do teste físico no dispositivo/GTO.
